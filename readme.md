# Make 10 Puzzle

4つの数字と四則演算で「10」を作るWebブラウザ向けパズルゲームです。

## 遊ぶ（URL）
https://make-10-puzzle.onrender.com/

## 機能
- **デイリーモード**: 1日1回限定のタイムアタック
- **練習モード**: 何度でも遊べるフリープレイ
- **ランキング**: クリアタイムのスコアボード（NGワードフィルター実装済）

## 構成
- **Frontend**: HTML / CSS / TypeScript (Vite)
- **Backend**: Python (FastAPI) / SQLite
- **Deploy**: Render
